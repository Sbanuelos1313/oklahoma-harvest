# From Our Place Mockup-Matched Asset Pack

This pack replaces the generic placeholder images with assets derived from the approved mockup images uploaded in chat.

Copy/merge the included `assets` folder into:

mobile/assets

Overwrite existing files when prompted.

Then run:

npx expo start --clear

Included:
- approved From Our Place logo
- root Expo icons/splash
- hero images matched to the mockups
- category image set
- product and vendor default images
- app icon set
